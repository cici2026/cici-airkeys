## Description (1048/4000)

```
Airkeys 把一部闲置手机变成冷钱包。手机始终离线；任何电脑的浏览器里打开网页助手（airkeys.app），查询余额、准备转账并广播。两边用摄像头读取对方屏幕上的动态码交换数据，不连线、不联网，也不用蓝牙。

使用方法
1. 打开飞行模式，关闭 Wi-Fi 和蓝牙。手机离线时，Airkeys 才会打开钱包。
2. 输入助记词，或扫描它的 SeedQR。助记词只在内存中，关闭钱包或 App 即被清除。
3. 向网页助手显示动态码，交出账户。网页助手只得到地址。
4. 在网页助手里准备转账，用手机扫描它的动态码。Airkeys 显示每个收款方、金额和手续费；按住签名，再把签好的交易显示给网页助手。

只给地址
多数钱包会把公钥交给联网的电脑。Airkeys 只给地址，并让每个账户使用独立的硬化路径，账户转出之前，它的公钥无人知晓。地堡模式在同一次签名里把转账后剩下的资产移到一个新账户。能破解椭圆曲线的量子计算机可以从公钥推出私钥；用 Airkeys，未花费的资产留在没人见过公钥的账户里。

网络
Bitcoin（原生隔离见证），以及 Ethereum、Base、Arbitrum、OP、Polygon、BNB Smart Chain、Avalanche 和你添加的任何 EVM 链上的 ETH 与 ERC-20 代币。未列入的代币也能签名，但会先显示警告。

保护
- 只在离线时工作：只要有网络连接、移动数据或蓝牙开着，Airkeys 只显示离线提示。
- 只签转账，签名前完整显示每一笔。
- 助记词从不保存。显示助记词的页面在多任务界面、录屏和屏幕镜像中被遮挡。
- 拒绝第三方键盘，助记词只用 Apple 自带键盘输入。

自带助记词
Airkeys 不创建钱包。它接受 12 到 24 个词的标准 BIP-39 助记词，可以带密码短语。它使用自己的派生路径，同一组助记词在其他钱包里显示的是不同的地址。恢复指南说明在没有 Airkeys 时如何用 Bitcoin Core 和 Foundry 取回资产。

开源
手机 App、它们共用的核心和网页助手都以 MIT 许可证开源。你可以免费自行编译；购买可以获得签名版本和更新，并支持后续开发。

重要
Airkeys 还很新（0.x 版本），没有经过第三方审计。请先用小额试用，并另行备份助记词。任何人，包括我们，都无法找回丢失的助记词。

需要 iOS 17 或更高版本。
网站：https://airkeys.app
```
